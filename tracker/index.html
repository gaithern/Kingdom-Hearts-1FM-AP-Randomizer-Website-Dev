How to use

Keep this page open while playing with KH1-RANDOMIZER installed. It reads your progress from the game on this computer, so it works offline and connected to Archipelago.

Each world shows how many important checks you have found there. The number turns blue once the world has none left.

For streaming, click Broadcast view and use that page's address as an OBS Browser Source. Add &layout=wide or &layout=tall to change the layout, and change bg=dark to bg=transparent or bg=green for the background.

If your browser asks to let this site access devices on your local network, allow it. That is how the page talks to the game.
