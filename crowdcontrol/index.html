KH1 Crowd Control lets Twitch Crowd Control redemptions trigger real effects in Kingdom Hearts Final Mix (PC) - spawn items and Heartless near Sora, pop messages on screen, grant abilities, hinder combos, or KO him outright.

The mod is a thin connector between the Crowd Control app and KH1-LUA-LIBRARY, which does the actual game-memory work. Both mods must be installed.

Installing

  1. Install Kingdom Hearts Final Mix (PC, Steam or EGS).
  2. Open KH1 at least once.
  3. Download and extract the latest version of OpenKH.
  4. Open "OpenKh.Tools.ModsManager.exe".
  5. You'll be presented with the set up wizard when opening the mods manager for the first time. Set up your game edition and installation folders (again, only Steam and EGS are currently supported).
  6. When prompted, install Panacea.
  7. When prompted, install Lua Backend for at least KH1.
  8. You may choose to create "steam_appid.txt".
  9. Extracting data is not required for Crowd Control.
  10. Ensure that you have selected "Kingdom Hearts 1" in the dropdown on the top right.
  11. Click the green "+" to install a new mod.
  12. In the "Add a new mod from GitHub" form, enter "gaithern/KH1-LUA-LIBRARY" and click "Install".
  13. You'll see the mod added to your mod list.
  14. Click the green "+" again to install another new mod.
  15. In the "Add a new mod from GitHub" form, enter "gaithern/KH1-CROWDCONTROL" and click "Install".
  16. You'll see the second mod added to your mod list.
  17. Click the checkbox next to both mods.
  18. Click "Mod Loader" at the top, and then "Build and Run." The game will open with your new mods installed.
  19. The game should now automatically communicate with the Crowd Control desktop app.
